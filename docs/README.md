# Documentation Cartomize

Cartomize permet d’analyser des données géospatiales et de produire des cartes depuis Python, Jupyter ou une interface graphique.

## Utilisation

| Guide | Contenu |
|---|---|
| [API Python](PYTHON_API.md) | Fonctions, paramètres et exemples Python |
| [Interface de bureau](WORKBENCH.md) | Ouverture des données, traitements et projets |
| [Panneaux et vues](DYNAMIC_WORKSPACE.md) | Placement des outils, fenêtres détachées et dispositions |
| [Visualisation des résultats](RESULTS_WORKSPACE.md) | Cartes, tableaux, graphiques et comparaison |
| [Jupyter](NOTEBOOKS.md) | Installation, noyau Python et utilisation des notebooks |

## Traitements

| Guide | Contenu |
|---|---|
| [Préparation des images satellites](IMAGERY_AUTOMATIC.md) | Bandes, couverture, grilles, mosaïque et découpage |
| [Statistiques raster](RASTER_STATISTICS.md) | Calculs zonaux, voisinages et synthèses |
| [Classification](CLASSIFICATION.md) | Apprentissage, validation et modèles |
| [Chaînes de traitements](PROCESSING.md) | Plans, recettes et exécution par lot |
| [Moteurs de calcul](EXECUTION.md) | Exécution locale, distribuée et GPU |

Les [exemples d’imagerie](DEMONSTRATION_1.0.md) utilisent des données synthétiques pour reproduire les différentes situations de couverture.

Les anomalies peuvent être signalées dans le [suivi du projet](https://github.com/cedrick14/cartomize-python/issues), avec les données minimales et les étapes nécessaires à leur reproduction.
