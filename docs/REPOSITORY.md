# Organisation du dépôt

Le dépôt `cedrick14/cartomize-python` contient la bibliothèque Python autonome Cartomize et son interface graphique. Le paquet PyPI et le module Python portent le nom `cartomize`. La version courante est **1.0**.

| Répertoire ou fichier | Contenu |
|---|---|
| `src/cartomize` | API, traitements, interface graphique et ressources |
| `tests` | Tests unitaires et d’intégration |
| `examples` | Exemples Python et protocole de mesure des performances |
| `docs` | Documentation technique et guides d’utilisation |
| `scripts` | Contrôles de démarrage et des distributions |
| `.github/workflows` | Intégration continue et publication PyPI |
| `pyproject.toml` | Métadonnées, dépendances et configuration de construction |

Le plugin QGIS est maintenu séparément. Les passerelles natives de la bibliothèque sont des fonctions d’interopérabilité facultatives.

Les licences et attributions sont consignées dans [NOTICE.md](../NOTICE.md), [PROVENANCE.json](PROVENANCE.json) et [BRANDING.md](BRANDING.md).
